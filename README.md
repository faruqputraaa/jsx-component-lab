# React JSX Props Lab

## React Environment Setup

Project React berhasil dibuat menggunakan Vite dan seluruh dependency berhasil diinstall dengan baik. Development server dapat dijalankan menggunakan perintah `npm run dev` tanpa muncul error. Hal ini membuktikan bahwa environment React sudah terkonfigurasi dengan benar dan aplikasi dapat dijalankan di browser dengan normal.

---

## Functional Component Using JSX

Functional component berhasil dibuat menggunakan JSX pada file `Welcome.jsx`. Component menggunakan syntax JSX untuk menampilkan elemen heading dan berhasil diexport menggunakan `export default`. Tidak ditemukan syntax error selama proses build maupun saat aplikasi dijalankan.

---

## Import and Render Component

Component `Welcome` berhasil diimport ke dalam file `App.jsx` dan ditampilkan menggunakan syntax `<Welcome />`. Component dapat dirender dengan baik di browser tanpa runtime error. Hal ini membuktikan bahwa proses import dan rendering component React berjalan dengan benar.

---

## Passing Props

Component `UserCard` berhasil menerima data melalui props. Data seperti `name` dan `email` dapat ditampilkan secara dinamis menggunakan `props.name` dan `props.email`. Hal ini menunjukkan bahwa component React dapat menerima dan menggunakan data dari parent component dengan benar.

---

## Reusable Component

Component `UserCard` berhasil digunakan beberapa kali dengan nilai props yang berbeda. Setiap component menampilkan data yang berbeda sesuai props yang diberikan. Hal ini membuktikan bahwa component bersifat reusable dan dapat digunakan kembali untuk menampilkan data dinamis secara efisien.
